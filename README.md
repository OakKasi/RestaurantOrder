# 🍽️ Restaurant Order App (ระบบจัดการสั่งอาหารในร้านอาหาร)

แอปพลิเคชันจัดการระบบสั่งอาหารและบิลสำหรับร้านอาหาร พัฒนาด้วย React Native และ Expo พร้อมระบบฐานข้อมูลออฟไลน์ SQLite

## 📱 ฟังก์ชันการทำงานของแอปพลิเคชัน

1. **ผังโต๊ะอาหาร (Tables):** แสดงสถานะโต๊ะอาหาร (ว่าง / ไม่ว่าง) และเลือกโต๊ะเพื่อเริ่มสั่งอาหาร
2. **สั่งอาหาร (Menu & Order):** แสดงรายการอาหาร แยกหมวดหมู่ เพิ่ม/ลดจำนวน และส่งรายการอาหารเข้าสู่ระบบ
3. **สรุปรายการบิล (Bill Summary):** คำนวณยอดเงินรวม ตรวจสอบรายการที่สั่ง และชำระเงิน/เคลียร์โต๊ะ
4. **หน้าจอครัว (Kitchen Order):** แสดงออเดอร์ที่เข้ามาในครัวแบบเรียลไทม์ พร้อมปุ่มอัปเดตสถานะอาหาร
5. **ประวัติบิลย้อนหลัง (Bill History):** ดูประวัติการชำระเงินและรายการอาหารในแต่ละบิล
6. **จัดการเมนูอาหาร (Add/Manage Menu):** เพิ่ม แก้ไข ปรับเปลี่ยนราคา และจัดการรายการเมนูอาหารในร้าน
7. **แดชบอร์ดสรุปยอดขาย (Dashboard):** ดูสถิติและสรุปยอดขายของร้านอาหาร

## 🛠️ เทคโนโลยีและเครื่องมือที่ใช้ (Tech Stack)

- **Framework:** Expo SDK 57 (Managed Workflow)
- **UI & Logic:** React Native 0.86, React 19
- **Database:** `expo-sqlite` (Local SQLite Database ภายในเครื่อง)
- **Navigation:** `@react-navigation/native`, `@react-navigation/native-stack`
- **UI Components & Safe Area:** `react-native-safe-area-context`, `react-native-screens`, `expo-status-bar`

## 🚀 วิธีการติดตั้งและรันโปรเจกต์

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. เริ่มต้น Development Server
```bash
npx expo start
```
*(หรือใช้ `npm start`)*

### 3. ทดสอบการใช้งาน
- **ผ่านโทรศัพท์มือถือจริง (แนะนำ):**
  - **Android:** เปิดแอป **Expo Go** แล้วสแกน QR Code จาก Terminal
  - **iOS:** ใช้แอป **Camera (กล้องถ่ายรูป)** สแกน QR Code แล้วกดเปิดใน **Expo Go**
  - *(หมายเหตุ: อุปกรณ์มือถือและคอมพิวเตอร์ต้องเชื่อมต่อ Wi-Fi วงเดียวกัน)*
- **ผ่าน Emulator / Simulator:**
  - กดปุ่ม `a` ใน Terminal เพื่อเปิดบน **Android Emulator**
  - กดปุ่ม `i` ใน Terminal เพื่อเปิดบน **iOS Simulator** (macOS)
  - กดปุ่ม `w` เพื่อเปิดดูเวอร์ชันเว็บบนเบราว์เซอร์
