# RestaurantOrder

แอปพลิเคชันระบบสั่งอาหาร (Restaurant Order) พัฒนาด้วย **React Native / Expo**

---

## 🚀 วิธีเริ่มต้นสำหรับสมาชิกในทีม (Getting Started)

### 1. ติดตั้ง Dependencies
หลังจาก clone โปรเจกต์ลงเครื่องแล้ว ให้เปิดโฟลเดอร์ใน Terminal แล้วรันคำสั่ง:

```bash
npm install
```

### 2. รันโปรเจกต์ (Development Server)

```bash
npx expo start
```
หรือ
```bash
npm start
```

### 3. เปิดทดสอบบนมือถือ
- **iOS / Android**: โหลดแอป **Expo Go** บนมือถือ
- สแกน QR Code ที่แสดงบน Terminal หรือหน้าต่าง Metro Bundler (ต้องอยู่ใน Wi-Fi วงเดียวกัน)
- หากใช้ Emulator / Simulator: กด `a` สำหรับ Android Emulator หรือ `i` สำหรับ iOS Simulator

---

## 🛠 Libraries & Tech Stack ที่ติดตั้งไว้แล้ว
- **Expo SDK 57**
- **React Native 0.86**
- **@react-navigation/native-stack** (สำหรับจัดการหน้าจอและ Navigation)
- **expo-sqlite** (สำหรับฐานข้อมูล SQLite ภายในเครื่อง)
- **react-native-safe-area-context** & **react-native-screens**
